# دار السدر · Dar Sidr

[معاينة المتجر](https://notwork2.github.io/dar-sidr-preview/) · [معاينة لوحة الإدارة](https://notwork2.github.io/dar-sidr-preview/admin/)

تصفّح خزانة العطور بالعربية أو الإنجليزية، وافتح أحد المنتجات لتجربة العرض المتحرّك. في لوحة الإدارة يمكنك مراجعة طلب تجريبي، تفاصيل الفاتورة، وكميات المخزون.

هذه معاينة ببيانات تجريبية. يمكن فتح الرابطين مباشرة دون تسجيل دخول. الطلبات والمدفوعات والتعديلات الإدارية معطّلة.
